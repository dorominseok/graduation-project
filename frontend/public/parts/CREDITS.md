# 부위 해부도

종목 고르기의 부위 카드 그림 13장(`<분류>.webp`, 분류 이름을 소문자·하이픈으로).

- Google Gemini 이미지 생성으로 만들었다(2026-10). 같은 프롬프트에 대상 근육·방향·구도만 바꿔 한 세트로 맞췄다.
- 생성 원본(2048px PNG)은 저장소에 넣지 않고 로컬 `sample/anatomy/`에 보관한다.
- 앱용으로 오른쪽 아래 생성 표시를 지우고, 검은 바탕을 투명하게 뺀 뒤(가장자리에서 이어진 검정만 — 몸 안의 어두운 골은 남긴다) 가운데를 4:3으로 잘라 480×360 WebP로 줄였다.
